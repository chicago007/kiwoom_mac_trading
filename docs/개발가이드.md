# 개발 가이드

Mac용 키움 REST API 기반 미국주식 수동매매 웹앱(0.21)의 로컬 실행 안내입니다.

키움증권 REST API를 이용하여 macOS에서 미국주식 시세·호가·잔고를 확인하고, 사용자가 직접 확인한 후 수동으로 주문할 수 있도록 만든 개인용 웹앱입니다.

본 프로젝트는 키움증권이 제공하거나 승인한 공식 HTS/WTS/MTS가 아니며, 키움증권과 제휴·협력 관계가 없습니다.

본 프로젝트는 개발자 본인의 키움증권 계좌에서 개인적으로 사용하기 위해 개발한 프로젝트입니다. 제3자의 계좌 운용, 투자자문, 투자일임 또는 주문 대행을 목적으로 하지 않습니다.

## 구성

```
kiwoom_mac_trading/
  VERSION
  backend/app/       FastAPI
  frontend/src/      Next.js
  docs/
  .env.example
```

브라우저는 키움에 직접 호출하지 않습니다. 프론트 → `/api/*` → FastAPI → 키움.

자동매매 전략·스케줄러는 이 프로젝트에 없습니다. 조건 엔진이 필요하면 `kiwoom_autotrading`을 씁니다.

## 로컬

1. 맥에 깔 프로그램과 clone부터 실행까지는 루트 [README.md](../README.md)의 **맥에서 설치하기**를 따른다. 키움 가입·키 발급은 [사전절차.md](./사전절차.md).
2. 루트에서 `./dev.sh` 하면 UI **3010**과 API **8010**을 같이 켠다. 안 쓸 때는 `Ctrl+C`. 킬스위치만으로는 시세 호출이 멈추지 않는다.
3. 키움 키는 `.env`에만 둔다. `KIWOOM_ENABLED=false`가 기본이다.
4. 화면은 `http://127.0.0.1:3010`이다. 8010에서 `/trade` 등을 열면 3010으로 넘긴다.
5. uvicorn은 `--timeout-graceful-shutdown 1`을 권장한다. SSE가 열려 있으면 reload가 멈출 수 있다.

## 작업 순서

1. 종합 화면에서 시세·호가·차트·잔고가 키움과 맞는지 확인한다.
2. `KIWOOM_ORDERS_ENABLED=true`로 소액 지정가 1주를 확인 후 연다. 킬스위치를 켠 채 테스트하지 않는다.
3. 조건검색·자동 주문은 넣지 않는다.

구현 기준은 [개발문서.md](./개발문서.md)와 공식 예제입니다.

## 프론트

- 상태: `frontend/src/lib/store.tsx`
- API 클라이언트: `frontend/src/lib/api.ts`
- 종합: `frontend/src/components/TradingDesk.tsx`
- 종합2: `frontend/src/components/TradingDesk2.tsx`
- 관심종목: `frontend/src/components/WatchlistPanel.tsx`
- 거래내역: `frontend/src/components/TradesPanel.tsx`
- 지수·환율: `frontend/src/components/MarketStrip.tsx`
- `/api/*`는 Next 개발 서버가 `127.0.0.1:8010`으로 넘깁니다. SSE는 버퍼를 피하려고 `:8010`으로 직접 엽니다.

## 백엔드

- 상태: `backend/app/store.py` (메모리. 재시작 시 초기값으로 돌아감)
- 키움: `backend/app/kiwoom_gateway.py`
- 실시간 10호가: `backend/app/book_hub.py` (`FT`)
- 라우트: `backend/app/main.py`
