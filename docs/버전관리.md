# 버전 관리

Mac용 키움 REST API 기반 미국주식 수동매매 웹앱의 버전 규칙입니다. 지금 제품 버전은 **0.2**입니다.

본 프로젝트는 키움증권이 제공하거나 승인한 공식 HTS/WTS/MTS가 아니며, 키움증권과 제휴·협력 관계가 없습니다. 개발자 본인의 키움증권 계좌에서 개인적으로 사용하기 위해 만든 것이며, 제3자의 계좌 운용, 투자자문, 투자일임 또는 주문 대행을 목적으로 하지 않습니다.

## 번호

- 제품 버전은 `VERSION` 한 줄입니다. 지금 **0.2**입니다.
- 다음부터 **0.01씩** 올립니다: `0.21` → `0.22` → …
- 0.1은 0.10과 같습니다. 표기는 `0.1`을 유지합니다. 0.2는 0.20과 같습니다.
- npm/PyPI용 `x.y.z`가 필요하면 `0.2` → `0.2.0`으로 맞춥니다.

## 한 버전에서 할 일

1. `VERSION`을 새 번호로 바꾼다.
2. `frontend/src/lib/version.ts`, `backend/app/__init__.py`, 패키지 `version` 필드를 맞춘다.
3. `CHANGELOG.md` 맨 위에 항목을 적는다.
4. 커밋 메시지에 버전을 넣는다. 예: `Release 0.21`
5. 태그: `git tag -a v0.21 -m "v0.21"`
6. `git push origin main --tags` (원격이 있을 때)

## 브랜치

- `main` — 동작하는 최신
- 기능 작업은 `feat/...` 또는 그냥 `main`에 직접 (개인 저장소)

## 커밋

- 한 커밋은 한 가지 이유
- 비밀(`.env`, App Key)은 커밋하지 않는다
- 실주문 연동을 넣는 버전은 CHANGELOG에 **키움 실호출**이라고 분명히 적는다
