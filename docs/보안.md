# 보안

- App Key / Secret은 `.env` 또는 OS 키체인만 사용한다. Git에 올리지 않는다.
- `.env.example`에는 빈 값만 둔다.
- 브라우저는 키움에 직접 요청하지 않는다.
- 헤더에 운영/모의 모드를 항상 보여 실전 오인주를 줄인다.
- 실주문은 2단계 확인. 이 앱에는 자동매매 전략이 없다.
- 킬스위치는 신규 매수·매도를 막는다. 취소는 허용한다. 재시작하면 꺼진다. 안 쓸 때는 `Ctrl+C`로 프로세스를 끈다.
- 공개 이슈·스크린샷에 계좌번호·키·잔고를 올리지 않는다.

본 프로젝트는 키움증권이 제공하거나 승인한 공식 HTS/WTS/MTS가 아니며, 키움증권과 제휴·협력 관계가 없습니다.

본 프로젝트는 개발자 본인의 키움증권 계좌에서 개인적으로 사용하기 위해 개발한 프로젝트입니다. 제3자의 계좌 운용, 투자자문, 투자일임 또는 주문 대행을 목적으로 하지 않습니다. 실주문·매매 결과는 본인 책임입니다. 실제 가동 전에 최소 수량으로 주문 테스트를 하세요.
