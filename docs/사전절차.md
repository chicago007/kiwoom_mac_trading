# 개발 전 사전 절차

Mac용 키움 REST API 기반 미국주식 수동매매 웹앱을 쓰기 전에 키움 계좌·OpenAPI 키와 맥에 깔 프로그램을 맞춥니다.

키움증권 REST API를 이용하여 macOS에서 미국주식 시세·호가·잔고를 확인하고, 사용자가 직접 확인한 후 수동으로 주문할 수 있도록 만든 개인용 웹앱입니다. 본 프로젝트는 키움증권이 제공하거나 승인한 공식 HTS/WTS/MTS가 아니며, 키움증권과 제휴·협력 관계가 없습니다. 개발자 본인의 키움증권 계좌에서 개인적으로 사용하기 위해 만든 것이며, 제3자의 계좌 운용, 투자자문, 투자일임 또는 주문 대행을 목적으로 하지 않습니다.

맥에서 이 앱만 켜 보려면 루트 [README.md](../README.md)의 **맥에서 설치하기**를 먼저 본다. 이 문서는 키움 계좌·OpenAPI 키와, 개발 PC에 깔 프로그램의 상세다.

코딩을 시작하기 전에 **키움 쪽 가입·신청**과 **PC에 깔 프로그램**을 먼저 맞춘다.  
REST API는 영웅문 OCX가 필요 없다. Windows 전용 OpenAPI+나 해외파생 OpenAPI-W는 설치하지 않는다.

기준 문서: [키움증권 REST API 공식 저장소](https://github.com/Kiwoom-Securities/Kiwoom-REST-API), [OpenAPI 포털](https://openapi.kiwoom.com/main/home)

---

## 한눈에 보는 순서

```
1. 키움증권 계좌 개설
2. 해외주식(미국주식) 거래 신청 + (권장) 달러 환전
3. OpenAPI 포털 로그인 → REST API 사용 신청 → 앱 등록 → App Key/Secret 발급
4. Mac에 Python 3.13, uv, kwcli 설치
5. kiwoomcli setup 으로 인증 확인
6. (웹앱용) Node.js 설치
7. (선택) 공식 예제 저장소 clone, Postman
```

0~2번은 키움 심사·약관 동의가 있어 당일 안 끝날 수 있다. 3번 키가 나와야 API 연동을 검증할 수 있다.

---

## A. 키움증권 쪽에서 할 일

영웅문(HTS/MTS)은 API 호출에 필수는 아니다. 다만 계좌 개설, 해외주식 신청, 환전, 관심종목 확인에는 쓰는 편이 편하다.

### A-1. 키움증권 계좌

- 본인 명의 키움 위탁계좌가 있어야 한다.
- 없으면 [키움증권](https://www.kiwoom.com/) 또는 앱 **영웅문S**에서 비대면 계좌를 개설한다.
- 준비물: 신분증, 본인 명의 휴대폰, 타행 계좌(1원 인증).
- 공동인증서 또는 간편인증으로 로그인할 수 있게 해 둔다.

이 계좌가 없으면 OpenAPI 포털에 들어가도 앱키를 쓸 실계좌가 없다.

### A-2. 해외주식(미국주식) 거래 신청

국내주식만 되는 계좌로는 미국주식 주문이 거절된다. 영웅문S 또는 키움 홈페이지에서 아래를 확인한다.

1. **해외주식 거래 신청 / 해외주식 약관·위험고지 동의**
2. 미국(나스닥·뉴욕·아멕스) 거래가 가능한 상태인지
3. 필요하면 **달러 환전** (1차는 달러 예수금이 있을 때 매수하는 것으로 설계)

메뉴 이름은 앱 버전에 따라 `해외주식 > 거래신청`, `상품신청`, `약관동의` 등으로 다를 수 있다. 안 보이면 키움 고객센터(1544-9000)에 “REST API로 미국주식을 주문하려면 계좌에 어떤 신청이 필요한가”라고 확인한다.

OpenAPI 사용 신청과 해외주식 거래 신청은 별개다. 둘 다 되어 있어야 한다.

### A-3. OpenAPI 포털 — REST API 키 발급

주소: [https://openapi.kiwoom.com/main/home](https://openapi.kiwoom.com/main/home)

공식 README의 발급 절차:

1. OpenAPI 포털에 **키움 계좌로 로그인**한다.
2. **OpenAPI 사용 신청**을 한다. (이용약관·개인정보 동의)
3. **앱(App)을 등록**한다. 앱 이름 예: `kiwoom-mac-trading`
4. 등록한 앱에서 **App Key / App Secret**을 확인·발급한다.
5. 운영과 모의투자를 같이 쓰려면 **키를 따로** 받는다. 두 키는 호환되지 않는다.

받을 것:

| 환경 | 용도 | 비고 |
| --- | --- | --- |
| 운영(real) App Key / Secret | 실제 미국주식 조회·주문 | `https://api.kiwoom.com` |
| 모의(demo) App Key / Secret | 조회·연동 테스트 | `https://mockapi.kiwoom.com` |

미국주식 **모의주문**이 되는지는 포털 안내를 다시 본다. 국내주식 모의만 되는 경우가 있어, 주문 검증은 소액 실전으로 갈 수 있다.

키 보관:

- 메일, 메신저, Git, 스크린샷에 넣지 않는다.
- 로컬은 다음 절의 `kiwoomcli setup`(macOS 키체인)을 권장한다.

레거시 **OpenAPI+**(KOA Studio, 32비트, 영웅문 자동로그인)는 이 프로젝트와 무관하다. 잘못 신청하지 않는다.

### A-4. (선택) 영웅문에서 관심종목

앱은 자체 관심종목 DB를 쓴다. 키움 HTS 관심종목을 가져오려면(`usa20200`, `usa20201`) 영웅문에서 미국주식 관심그룹을 하나 만들어 두면 나중에 import 테스트가 쉽다.

## B. 개발 PC에 설치할 것 (macOS)

이 Mac 기준이다. OpenAPI+용 32비트 Python, PyQt5, KOA Studio는 설치하지 않는다.

### B-1. 필수 — API 연동 검증

| 프로그램 | 버전 | 설치 | 확인 |
| --- | --- | --- | --- |
| Xcode Command Line Tools | 최신 | `xcode-select --install` | `git --version` |
| Homebrew (권장) | 최신 | [brew.sh](https://brew.sh) | `brew -v` |
| Python | **3.13 이상** | `brew install python@3.13` | `python3 --version` |
| uv | 최신 | `brew install uv` 또는 아래 스크립트 | `uv --version` |
| 키움 CLI | PyPI `kwcli` | `uv tool install kwcli` | `kiwoomcli --help` |

uv를 Homebrew 없이 설치할 때:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

설치 후 터미널을 새로 연다. `kiwoomcli`가 안 보이면 `uv tool update-shell` 후 다시 연다.

### B-2. 필수 — 웹앱 프론트 (개발 착수 시)

| 프로그램 | 버전 | 설치 | 확인 |
| --- | --- | --- | --- |
| Node.js | 20 LTS 이상 | `brew install node@20` 또는 [nodejs.org](https://nodejs.org/) | `node -v` |
| npm 또는 pnpm | Node에 포함 / `brew install pnpm` | `npm -v` |

백엔드만 먼저 검증할 거면 Node는 미뤄도 된다.

### B-3. 선택

| 프로그램 | 용도 |
| --- | --- |
| [공식 저장소 clone](https://github.com/Kiwoom-Securities/Kiwoom-REST-API) | 미국주식 예제·스펙 확인 |
| [Postman](https://www.postman.com/downloads/) | 공식 Collection Import |
| Cursor / VS Code | 이 프로젝트 개발 |
| 영웅문S (iOS/Android) 또는 영웅문4 | 계좌·환전·수동 주문 확인 |

공식 예제 저장소를 받을 때:

```bash
git clone https://github.com/Kiwoom-Securities/Kiwoom-REST-API.git
cd Kiwoom-REST-API
uv sync
```

## C. 인증이 됐는지 확인

App Key를 받은 뒤, 공식 권장 순서대로 확인한다.

```bash
kiwoomcli setup
```

대화형 입력:

1. 계좌 별칭 — 예: `실전계좌` 또는 `모의계좌`
2. 서버 — 처음에는 `[1] demo`가 안전. 미국 실조회가 필요하면 `[2] real`
3. 해당 환경의 App Key / Secret (화면에 안 보임)

그다음:

```bash
kiwoomcli auth status
kiwoomcli overseas stocks info --exchange NASDAQ --code AAPL
```

미국 종목 정보가 나오면 키·해외주식 권한이 붙은 것이다.  
여기서 막히면 코드를 짜기 전에 포털 신청, 키 종류(운영/모의), 해외주식 약관을 다시 본다.

주문 계열 명령은 `--confirm` 등이 있다. 확인 전에는 실행하지 않는다.

서버처럼 키체인을 못 쓰는 환경만 공식 `.env`를 쓴다.

```
KIWOOM_MODE=real          # 또는 demo
APP_KEY=                  # 운영
APP_SECRET=
APP_KEY_MOCK=             # 모의
APP_SECRET_MOCK=
```

`.env`는 Git에 올리지 않는다. `kiwoomcli setup`을 쓴 맥에서는 `.env`를 만들지 않는 것이 공식 권장이다. 둘을 같이 쓰면 충돌한다.

## D. 설치하지 말 것

| 항목 | 이유 |
| --- | --- |
| OpenAPI+ (OCX), KOA Studio | Windows 32비트 레거시. REST와 다름 |
| OpenAPI-W | 해외선물·옵션용. 미국주식이 아님 |
| 32비트 Python, PyQt5 | REST에는 불필요 |
| 영웅문 자동로그인 매크로 | 토큰 인증으로 대체됨 |
