## 1. 목적

키움증권 REST API를 이용하여 macOS에서 미국주식 시세·호가·잔고를 확인하고, 사용자가 직접 확인한 후 수동으로 주문할 수 있도록 만든 개인용 웹앱이다. 본 프로젝트는 키움증권이 제공하거나 승인한 공식 HTS/WTS/MTS가 아니며, 키움증권과 제휴·협력 관계가 없다. 개발자 본인의 키움증권 계좌에서 개인적으로 사용하기 위해 만든 것이며, 제3자의 계좌 운용, 투자자문, 투자일임 또는 주문 대행을 목적으로 하지 않는다.

1. 관심종목을 관리한다.
2. 호가·차트·잔고를 한 화면에서 본다.
3. 확인 후 매수·매도·정정·취소를 낸다.

자동매매, 종가/시초가 조건 엔진, 전략 스케줄러는 **넣지 않는다.** 그 기능은 `kiwoom_autotrading`에 둔다.

레거시 OpenAPI+(OCX)나 OpenAPI-W는 쓰지 않는다. Windows 전용 COM은 맥에서 동작하지 않는다.

## 2. 범위

### 포함

- 키움 앱키로 토큰 발급·캐시
- 키움 HTS 관심종목 불러오기. 앱에서 추가·삭제 후 저장(앱 보관). 그룹 추가는 하지 않음
- 현재가·10호가·차트
- 예수금·잔고·당일 주문/체결·기간 거래내역
- 수동 주문, 정정, 취소
- 킬스위치, 주문가능수량, 종목당 최대 수량, 1회 최대 금액
- 대표지수·환율 (거래소 지수·선물, 키움 적용환율)

### 제외

- 자동매매 전략, 조건 평가, 장 시각 스케줄러
- 국내주식, 미국 외 시장
- 해외선물·옵션 (OpenAPI-W)
- 레거시 OpenAPI+ (Windows OCX)
- 다중 사용자 SaaS

## 3. 시스템 구조

```
[브라우저]  http://127.0.0.1:3010
   │ 종합 / 로그 / 설정
   ▼
[웹 프론트]  Next.js
   │ /api/*  →  127.0.0.1:8010
   ▼
[앱 백엔드]  FastAPI + 공식 kiwoom
   ├─ 관심종목
   ├─ 시세·호가(FT)·차트
   ├─ 기간 거래내역
   ├─ 수동 주문
   └─ 킬스위치
```

브라우저는 키움에 직접 호출하지 않는다. 앱키는 `.env`에만 둔다.

## 4. 이 앱이 쓰는 키움 API

미국주식은 `/api/us/*`만 쓴다. 국내주식 `/api/dostk/*`와 섞지 않는다.

### 주문 — `/api/us/ordr`

| api-id | 기능 |
| --- | --- |
| `ust20000` | 매수 |
| `ust20001` | 매도 |
| `ust20002` | 정정 (`mdfy_uv`) |
| `ust20003` | 취소 (원주문 전량) |
| `ust31490` | 주문가능수량 |

거래소: `ND` NASDAQ, `NY` NYSE, `NA` AMEX.

지정가 `trde_tp=00`, 시장가 `03`. 정정·취소는 원주문번호 기준이다.

### 시세·차트

| api-id | 용도 |
| --- | --- |
| `usa20100` | 현재가, 시가, 전일종가, 거래정지 |
| `usa20101` | 10호가 REST. 이후는 `FT` |
| `usa06012` | 일봉 |
| `usa06011` | 분봉 |

가격 필드는 키움 부호 규칙을 따른다. 화면 등락은 절댓값으로 보여 주고 색은 한국 HTS(상승 빨강, 하락 파랑)다.

### 관심·계좌·실시간

| api-id / 예제 | 용도 |
| --- | --- |
| `usa20200` / `usa20201` | HTS 관심 그룹 조회. 공식 REST에 쓰기 API 없음 |
| `ust21110` | 예수금 |
| `ust21070` | 잔고. `pl_amt` / `pl_amt_krw`는 수수료 포함 |
| `ust21150` | 당일 체결 |
| `ust21100` | 기간 거래내역. HTS 거래내역과 같은 필드 |
| `ust21050` | 미체결 |
| `ust31301` | 환전 적용환율 |
| `usa10098` / `usa10099` | 티커 검색 |
| `FT` | 실시간 10호가 |
| `FE` | 실시간 체결가 (후순위) |
| `F4` / `F5` | 주문확인·체결 (후순위) |

## 5. 관심종목

키움 HTS에 있는 관심그룹을 불러와 종합 화면에서 본다. 앱에서 종목을 추가·삭제하고 저장할 수 있다. 공식 REST는 조회만 있어 영웅문 쓰기는 반영되지 않는다. 새 그룹은 만들지 않는다.

종목 키는 `(stex_tp, stk_cd)`이다. `BRK.B`처럼 점 있는 티커는 URL 인코딩한다.

---

## 6. 화면

1. **종합** (`/`, `/trade`) — 지수·환율, 10호가, 주문창, 차트, 잔고, 관심종목, 주문내역/당일체결/거래내역 탭
2. **로그** — 주문·차단·API 응답
3. **설정** — 계좌 모드, 한도

`/orders`·`/portfolio`는 종합으로 이동한다. 실주문은 2단계 확인이 필요하다.

---

## 7. 앱 API

백엔드만 키움을 호출한다. 호스트는 `http://127.0.0.1:8010`. 상세는 [API.md](./API.md).

주문 요청은 `client_order_id`를 받는다. 재시도로 주문이 두 번 나가지 않게 한다.

## 8. 안전장치

| 장치 | 내용 |
| --- | --- |
| 수동만 | 조건이 맞아도 주문이 나가지 않는다. 사람이 확인한 주문만 |
| 킬스위치 | 켜면 신규 매수·매도 차단. 취소는 허용. 재시작하면 꺼짐. 안 쓸 때는 프로세스 종료 |
| 모드 | `real` / `demo`는 설정으로만 전환 |
| 한도 | 일일 손실, 종목당 수량, 1회 금액 |
| 거래정지 | `trd_susp_tp`가 정지면 주문 안 함 |
| 가능수량 | 주문창·접수 직전 `ust31490` |
| 감사 로그 | 요청, `return_code`, `ord_no` (시크릿 제외) |
